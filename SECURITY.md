# Sicherheit / Security

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern über
GitHubs private Meldung: Reiter „Security“ → „Report a vulnerability“
(https://github.com/Codatus/kiekan/security/advisories/new).

Hilfreich sind: betroffene Version, Betriebssystem, eine Beispieldatei oder
die Schritte zum Nachstellen und was dabei passiert.

Besonders interessiert uns alles, was die KI-Schnittstelle betrifft
(Zugriff außerhalb der freigegebenen Ordner, Umgehen der Kennzeichnung
fremder Inhalte) sowie Abstürze oder Speicherfehler beim Öffnen präparierter
Dateien.

## Reporting vulnerabilities

Please do **not** open a public issue. Use GitHub's private reporting
instead: “Security” tab → “Report a vulnerability”. Include the affected
version, operating system and a sample file or steps to reproduce.

## Unterstützte Versionen / Supported versions

Sicherheitskorrekturen gibt es für die jeweils neueste Version.
Security fixes are provided for the latest release only.
