KiekAn! – Paketquelle für Ubuntu und Debian

Das Paket von GitHub Releases richtet diese Quelle beim Installieren selbst ein. Danach kommen neue Versionen mit den normalen Aktualisierungen.

Von Hand einrichten (Suite passend wählen: jammy = Ubuntu 22.04, noble = Ubuntu 24.04, bookworm = Debian 12, trixie = Debian 13):

sudo curl -fsSLo /usr/share/keyrings/kiekan-archive-keyring.gpg https://codatus.github.io/kiekan/apt/kiekan-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/kiekan.sources https://codatus.github.io/kiekan/apt/kiekan-noble.sources
sudo apt update && sudo apt install kiekan

apt fragt hier bei apt update nach neuen Versionen. KiekAn! selbst sendet nichts ins Netz. Abschalten: in /etc/apt/sources.list.d/kiekan.sources die Zeile Enabled: no ergänzen oder die Datei löschen.
